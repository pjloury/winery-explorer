# Winery logos

Circular map markers for the top-prestige wineries. Each `<slug>.png` is the
winery's own brand logo (emblem, crest, or wordmark), sourced from the winery's
official website, shown small for identification only — the same personal-use
basis as the bottle-label images. Wineries without a logo file here fall back to
a generated monogram marker in the app.

Placeholder/auto-generated logos and any that couldn't be confidently matched to
the correct winery were discarded rather than risk showing the wrong brand mark.
